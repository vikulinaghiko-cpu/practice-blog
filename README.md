# ПрактикаBlog

Учебное веб-приложение для кейс-задачи №3 производственной практики.

## Возможности
- регистрация и вход пользователя;
- создание, редактирование и удаление постов;
- подписка и отписка от пользователей;
- персональная лента на основе подписок;
- публичные публикации;
- публикации «только по запросу» с подтверждением автором;
- теги, фильтрация и сортировка публикаций;
- комментарии.

## Запуск
Требуется только Python 3.10+; внешние библиотеки не нужны.

```bash
python app.py
```

Открыть: http://127.0.0.1:8001

Демонстрационный пользователь: `demo` / `demo123`.
Автор закрытой публикации: `author` / `author123`.

База `blog.db` создаётся автоматически при первом запуске и заполняется демонстрационными данными.
